## Arquitetura da Informação

### Classificação

Os conteúdos são classificados em duas categorias principais: Unidades Curriculares e Projeto Integrador.

### Taxonomia

A estrutura segue uma organização hierárquica:

Portfólio Acadêmico > Categoria > Unidade Curricular ou Projeto > Atividade

Essa hierarquia permite identificar facilmente onde cada conteúdo está localizado.

### Metadados

Cada atividade pode conter informações como:

- Unidade Curricular
- Professor
- Tipo de atividade
- Tema
- Tecnologias utilizadas
- Palavras-chave

### Navegação

O README principal funciona como página inicial do portfólio e contém links para as diferentes Unidades Curriculares e para o Projeto Integrador.

### Encontrabilidade

Os diretórios e arquivos utilizam nomes descritivos e padronizados. Os READMEs também possuem títulos, descrições e palavras-chave que facilitam a identificação dos conteúdos.

### Relações entre conteúdos

As atividades podem possuir links para conteúdos relacionados, permitindo conectar disciplinas, tecnologias utilizadas e projetos desenvolvidos durante o curso.
