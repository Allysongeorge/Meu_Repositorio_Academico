# ConectaStart

## Sobre o projeto

O ConectaStart é um Projeto Integrador desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas.

A proposta consiste em uma plataforma voltada ao ecossistema de startups, reunindo informações, oportunidades, eventos, editais e recursos que possam auxiliar no desenvolvimento de novos negócios.
